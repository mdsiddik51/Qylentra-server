# 🚀 Qylentra Server

A secure and scalable backend API for the **Qylentra Doctor Appointment System**.  
This server handles authentication, doctor data, appointments, and user management.

---


## 📌 Key Features

- 🔐 JWT-based authentication system
- 👨‍⚕️ Doctor management (CRUD operations)
- 📅 Appointment booking and scheduling system
- 🧾 Secure user role handling (Admin / User / Doctor)
- ⚡ Fast RESTful API with Express.js
- 🛡️ Protected routes with middleware security
- 🗄️ MongoDB database integration

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB & Mongoose
- JSON Web Token (JWT)
- Cors
